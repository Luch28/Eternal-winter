## Eternal-winter
A fork of Minecraft Beta 1.7.3

You into an eternal winter, giving you just one day to find shelter. The freezing cold deals damage over time, so you'll need to craft *warm armor* to survive. 

Keep your temperature up by placing campfires or torches—but watch out, as both can burn out. Always keep a flint and steel handy! It's highly recommended to play this with friends. A server.jar file is available.

So you can set up your own server to play with friends.
